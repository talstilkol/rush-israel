# RUSH Israel — Lint Baseline

**Established:** RSH-007  
**Required command:** `npm run lint`

Lint is a blocking GitHub Actions step. The following exceptions are explicit,
path-scoped and do not disable their rules repository-wide.

| Path | Exception | Reason | Removal owner |
|---|---|---|---|
| `public/basis/**` | ignored | Vendored Khronos/Emscripten Basis transcoder output; application lint must not rewrite third-party generated bytes. | RSH-011 provenance lock |
| `src/game/roadShader.ts` | `@typescript-eslint/no-unsafe-function-type` | Existing Three.js compile callback surface predates typed renderer extraction. | RSH-017 |
| `src/game/spline.ts` | `prefer-const` | Existing tangent variables are grouped with mutable normal variables. | RSH-014/RSH-017 |
| `src/game/world.ts` | `no-var` | Two legacy shared scratch objects require refactoring during world-core extraction. | RSH-015 |

Warnings remain visible in CI but do not fail the gate. New errors outside these
exact paths fail `required-ci / validate`.
