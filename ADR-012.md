# ADR-012 — Pixel-golden and Ayalon lock join required npm test; remaining gates stay RED

**Date:** 2026-09-16
**Status:** accepted
**Supersedes:** the P1-12 golden/Ayalon-lock clause of ADR-010. Gate 7 stays GREEN. Gate 10 stays RED per ADR-011.

## Decision

Companion `scripts/check-damage-required.test.mjs` now also runs accepted
`ayalon-hash.mjs` and `pixel-golden.mjs` inside `npm test`. Those tests share
one file so Node runs them sequentially on port 8080 (no lock file). Hashed
`package.json` `qa:ci:raw` is unchanged. `hashalom-photo.mjs` is not added:
it writes `golden-baseline` PNG bytes. The 1800 s wall-clock soak is not
added. P1-12 stays **OPEN**. Live release gates stay **7/13**. Remaining
gates 1, 8, 9, 10, 12 and 13 stay **RED**. Frozen manifests stay 0/13.

## Why this is not a remaining-gate GREEN

Gate 6 was already GREEN from the Ayalon freeze and builder-import pins.
Running pixel-golden in required CI strengthens that evidence; it does not
open a new live gate. P1-17 stays **MITIGATED** because unit checkers lock
that token.
