# ADR-012 — Pixel-golden and Ayalon lock stay outside required npm test

**Date:** 2026-09-16
**Status:** accepted
**Does not supersede:** ADR-010 (gate 7) or ADR-011 (gate 10).

## Decision

PR #80 attempted to run accepted `ayalon-hash.mjs` and `pixel-golden.mjs`
inside `npm test`. Required CI failed (run 35099626005):

- `ayalon-hash` reports a live slice hash that does not match frozen
  `golden-baseline/ayalon.lock`. Bumping `AYALON_LOCK` would rewrite a
  freeze identity. The 36-hash Ayalon freeze remains the gate-6 authority.
- `pixel-golden` aborted with `ECONNRESET` and then `Error: ayalon` under
  unit-test load — the same class of flake as the rejected 20-cycle leak
  harness.

Those scripts stay outside required CI. Damage-smoke remains in `npm test`.
Hashed `qa:ci:raw` is unchanged. P1-12 stays **OPEN**. Live release gates
stay **7/13**. Remaining gates 1, 8, 9, 10, 12 and 13 stay **RED**. Frozen
manifests stay 0/13.

This PR records post-merge CI of PR #79 (run 35098117727, success).
